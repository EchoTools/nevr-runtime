# nEVR @VERSION@

@PLAYER_LINE@

- `@ZIP@`: install on PC (unzip, close the game, run `install.ps1`); also the dedicated server (`echovr_server.exe`) and `uninstall.ps1`.
- `@APK@`: install on Quest (published on the release host, not on this page).
- `@QUEST@`: for the Quest patcher; players do not need it.
- `install-nevr-runtime.exe` (inside the zip): the core installer the scripts run.
